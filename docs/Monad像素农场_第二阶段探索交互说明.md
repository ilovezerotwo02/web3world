# Monad 像素农场第二阶段探索交互说明

## 1. 产品变化

第二阶段将第一阶段的静态地图导航升级为全屏农场探索。课程、挑战、成长和奖励规则保持不变；地图承担角色移动、地点进入和成长反馈，长文本继续由 DOM/CSS 内容抽屉承载。

## 2. 用户形象

默认角色为“Monad 农场学徒”：中性年轻形象，深色短发、麦秆帽、蓝绿背带裤、紫色围巾和发光种子挎包。

角色图集为 `160×192` 透明 PNG，每帧 `32×48`：

- 行顺序：下、左、右、上。
- 列顺序：待机、行走 A、经过姿势、行走 B、互动。
- 地图中以 `64×96` 整数倍显示。
- 同一角色头像用于顶部 HUD、任务引导、底部导航和成长档案。

## 3. 控制规则

- `WASD` 和方向键：自由移动。
- 鼠标点击地面：寻路到最近可站立位置。
- 点击地点：自动寻路，抵达交互半径后打开地点内容。
- 靠近地点后按 `E`、空格或 Enter：立即进入。
- 键盘输入会取消当前鼠标路径。
- 抽屉、对话框、表单控件激活时停止人物移动。
- 窗口失焦或页面隐藏时清除按键状态，避免角色持续移动。

斜向输入会归一化为与单方向相同的速度。人物脚底使用独立碰撞盒，水面、建筑、池塘、树木、石壁、围栏和课程田内部不可穿越。

## 4. 地点与内容

| 地点 | 默认内容 | 进入方式 |
| --- | --- | --- |
| 知识塔 | 课程路线与理论章节 | 自动寻路或靠近后确认 |
| 种子小铺 | 课程种子 | 自动寻路或靠近后确认 |
| 课程土地 | 开荒、播种与作物 | 自动寻路或靠近后确认 |
| 进步工坊 | 章节挑战、最终验证与收获 | 根据学习进度自动选择内容 |
| 成长档案 | EXP、果实、成就与资格 | 点击顶部头像或底部入口 |

地点内容使用右侧抽屉覆盖地图，宽度为 `min(460px, 40vw)`。打开后人物暂停；Esc 或关闭按钮返回探索，并将焦点还给刚才的地点入口。

跨地点的课程动作会重新触发带路。例如在知识塔开启课程后，人物前往种子小铺；播种完成后，人物返回知识塔继续学习。

## 5. 场景状态

场景坐标使用原地图 `1586×992` 的世界坐标。位置独立保存到 `monad-pixel-farm:v35:scene-state`，结构为：

```json
{
  "version": 1,
  "x": 792,
  "y": 585,
  "direction": "down"
}
```

只接受版本、方向和可站立坐标全部有效的数据。损坏、越界或位于障碍物中的记录会回到中央路口。重置演示进度会同时清除学习和场景状态。

## 6. 验收入口

以下状态不写入本地进度：

```text
?preview=explore
?preview=walking
?preview=near-portal
?preview=drawer
?preview=profile-avatar
```

自动化测试覆盖斜向速度、碰撞、四个地点的 A* 路径、非步行区域投影、入口距离、镜头边界和场景存储校验。浏览器验收覆盖自动带路、抵达后打开、键盘进入、Esc 焦点恢复和刷新后位置保持。

## 7. 交付边界

- 桌面端最小宽度仍为 1100px。
- 不实现移动端虚拟摇杆。
- 不引入 Canvas 或游戏引擎。
- 不改变第一阶段课程与奖励状态机。
- 不接入钱包、Agent、NFT、账户或数据库服务。
