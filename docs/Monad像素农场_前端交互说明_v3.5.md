# Monad 像素农场前端交互说明 v3.5

## 1. 本轮目标

本轮将 PRD v3.5 中的“学习即种植”转成可直接演示的桌面端产品闭环。首个可完整通关的课程是 Web3 通识；Monad 基础与智能合约用于表达后续路线、解锁关系和平台扩展性。

目标演示尺寸为 1440×900。小于 1100px 的视口会显示桌面体验提示，不作为本轮移动端交付。

## 2. 信息架构

| 一级入口 | 用户要完成的事 | 核心内容 |
| --- | --- | --- |
| 农场 | 查看整体进度并继续下一步 | 地图热点、课程土地、作物成长状态、推荐行动 |
| 知识塔 | 理解三门课的顺序与解锁条件 | Web3 通识、Monad 基础、智能合约 |
| 种子小铺 | 领取首门课种子 | 账本星种、课程说明、已领取状态 |
| 进步工坊 | 从挑战进入最终验证 | 章节挑战、学习助手入口、结课小测入口 |
| 成长档案 | 查看学习结果 | EXP、等级、果实、成就、NFT 资格、解锁记录 |

全局顶部持续显示当前课程、五段成长进度和 EXP；底部导航提供稳定的跨区入口。

## 3. Web3 通识主流程

```text
农场首页
  → 知识塔选择 Web3 通识
  → 领取账本星种
  → 清理第一块土地
  → 播种
  → 第 1 章理论 → 第 1 组挑战
  → 第 2 章理论 → 第 2 组挑战
  → 第 3 章安全理论 → 第 3 组安全挑战
  → 选择结课验证方式
  → 结课小测 5 题全对
  → 作物结果
  → 亲手收获
  → 成长档案与 Monad 基础解锁
```

进度保存使用版本化键 `monad-pixel-farm:v35:web3-progress`。重复完成理论、挑战、小测或收获不会重复发放 EXP。

## 4. 页面与状态设计

### 农场首页

- 左侧是可点击的农场地图，四个地图热点直接对应平台一级功能。
- 课程土地同时表现 Web3 作物状态与另外两门课的锁定状态。
- 右侧行动面板只给一个明确的推荐动作，并配合路线概览和最近动态。
- 成长状态依次为：等待开始、已获得种子、土地已清理、已播种、已经发芽、已经开花、已经结果、已经收获。

### 理论章节

- 顶部表达章节序号、主题和当前状态。
- 正文使用目标、解释、术语、农场类比、操作提醒五层结构。
- “知识卡”承载为什么要知道、可见结果、状态变化和操作前检查。
- “聊聊这个概念”打开标准化提问预览，不制造真实 Agent 已连接的错觉。

### 挑战与重试

- 每次只显示一道选择题，选择后再提交。
- 错误回答说明判断依据，并提供明确的“再试一次”。
- 正确回答进入下一题；本章最后一题完成后进入下一章或最终验证。
- 发生过错误的章节记录一次学习奖励，重复错误不重复累计。

### 安全模式

- 第 3 章涉及私钥、助记词和盲签，使用深红警示条与盾牌标记。
- 文案明确错误操作的真实后果，不使用轻松化措辞。
- 知识卡和挑战反馈延续同一风险语义。

### 验证选择与 Agent 降级

- 学习助手被标记为推荐路径，结课小测是等价可用路径。
- 当前学习助手未连接真实服务。点击后展示“前端演示状态”、标准化提问预览和切换按钮。
- 从降级弹窗切换到结课小测不会丢失任何课程进度。

### 结课小测

- 五题同页，必须全部正确。
- 未作答或错误的题目会逐题标记；反馈说明剩余题数，其他正确答案保留。
- 全部正确后作物从开花进入结果，并增加 50 EXP。

### 收获与成长档案

- 结果页先汇总三章理论、三组挑战和结课小测，再要求用户亲手收获。
- 收获后记录守护浆果、账本守护者成就、NFT 领取资格和小测验证记录。
- NFT 只展示资格，明确标记“铸造未接入”。
- 收获增加 100 EXP，总计达到 255 EXP 和 LV.2 Web3 学徒，并解锁 Monad 基础入口。

## 5. 反馈与可访问性

- 关键状态同时使用图标、文字和颜色表达，不依赖单一颜色。
- 单选题使用原生 `fieldset`、`legend` 和 `radio` 语义。
- 弹窗带有明确标题、关闭按钮和 Escape 关闭能力，打开后焦点进入弹窗。
- 成功、错误和进度变化通过可读状态区与短时提示共同反馈。
- `prefers-reduced-motion` 下关闭非必要位移与动画。

## 7. 今晚版本边界

已完成的是前端产品闭环和本地状态持久化。以下能力没有接入，并在界面中明确表达真实状态：

- 钱包登录与链上读写
- 真实学习助手服务
- NFT 铸造与领取
- 账户、数据库与管理后台
- Monad 基础和智能合约两门课的完整课程内容
- 1100px 以下移动端完整布局

## 8. 开发与验证

```bash
npm run dev
npm run lint
npm test
```

自动化测试覆盖完整成长状态、奖励幂等、非法跳步、挑战错误奖励、存储结构和生产渲染关键内容。浏览器验收覆盖 1440×900 核心页面、错误重试、Agent 降级切换、五题全对、结果与收获档案。
