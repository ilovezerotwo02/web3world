
**设计计划**

目标：把当前“好看的像素农场入口”改成 v3.0 的主界面，左上是“知识塔”，右上是“种子小铺”，右下是“进步工坊”，左下是“三条课程土地 + 成长主线”。中央道路连接四个区域，让用户一眼看懂：从知识塔学习，到农田成长，到进步工坊验证，最后收获成就。
主界面保留 5 个核心入口：

1. **左上紫色神殿改为“知识塔”**
    
    - 保留紫色 Monad 能量风格，但建筑从神殿改成高耸知识塔。
	- 元素包括：书页浮雕、卷轴、发光菱形 Monad 标记、三层塔身。
	- 三层分别暗示三门课程：Web3 通识、Monad 基础、智能合约。
	- 塔门或塔身可用紫色发光表示“已解锁课程入口”。
	
2. **进步工坊**
    
    - 取代当前“修复温室”的功能感，不再表现破损温室。
    - 外观：像素工坊、蓝色书本图标、Agent 终端、闯关小门、考试卷轴。
    - 表达功能：Agent、章节闯关、结课考试。
    - 重点表达流程限制：
		- 入口前先放“闯关门”或“试炼牌”，标记为第一步。
		- 闯关门后方才显示两个分支入口：  
		    `Agent 提问` / `结课考试`
		- Agent 入口用蓝紫色发光终端表示，考试入口用卷轴/答题板表示。
3. **种子小铺**
    
    - 保留右上摊位，但从普通商店改为课程种子铺。
    - 摊位上展示 3 个像素种子袋：Web3、Monad、智能合约。
	    - `Web3 通识`
	    - `Monad 基础`
	    - `智能合约`
	- 三袋用不同标识区分：
	    - Web3：钱包/区块小图案。
	    - Monad：紫色菱形符号。
	    - 智能合约：卷轴/代码符号。
	- 状态表达：
	    - 已获得：袋口打开，有发光种子。
	    - 未解锁：袋子灰暗并带锁。
	    - 已完成：袋子旁有果实或徽章。
	
4. **未开荒土地 / 课程作物区**
      
    - - 左下农田作为主视觉核心，不再只是普通种植区。
	- 在农田上方或左侧做一条清晰成长链路：  
	    `课程种子 → 理论发芽 → 闯关开花 → 验证结果 → 收获成就`
	- 视觉表现为 5 个像素节点，沿田埂或木牌串联，像一个“课程作物成长进度条”。
	- 当前阶段用高亮色，未完成阶段弱化，已完成阶段带小对勾或发光边。
	- 左下农田不再是大面积普通作物，而是 3 条横向或斜向长条田块。
	- 每一条对应一门课程：
	    - 第一条：Web3 通识
	    - 第二条：Monad 基础
	    - 第三条：智能合约
	- 每条土地为 1 小格。
	- 每小格显示章节状态：
	    - 未开始：空土
	    - 理论完成（第一章）：嫩芽
	    - 闯关完成（第二章）：开花
	    - 验证通过（第三章）：结果
	    - 已收获：金色残光/果篮标记
	- 当前课程土地更亮，未解锁课程土地灰暗但可看出未来结构。
5. **玩家成就入口**
    
    - 设置在上方状态栏的最右边。
    - 外观：背包形状。
    - 表达：成就、NFT 领取资格。

**画面结构**

- 仍采用参考图的等距像素地图、黄昏紫色调、Monad 发光符号。

- 右侧或顶部叠加轻量 HUD：
    - 用户等级 / EXP
    - 当前课程：Web3 通识
    - 钱包状态
    - 当前成长阶段进度条：种子 → 发芽 → 开花 → 结果 → 收获

**需要弱化/移除**

- 不突出“修复温室任务”。
- 不表现自由经营、浇水、施肥、天气、体力、排行榜、多人农场。
- 不把种子小铺画成付费商店，避免误解为种子购买系统。
